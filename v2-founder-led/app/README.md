# Northstar Space Planner

Founder-led v2 is a working conversational home-gym planner. A typed server state
coordinates live catalogue data, deterministic recommendation/compatibility/room
fit/quote engines, an editable 2D plan, and a derived 3D room view.

## Local development

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

Open `http://localhost:5173`. The API listens on `http://localhost:8787`.
The planner works with the governed seed catalogue without an API key. Add a
fresh `OPENAI_API_KEY` to `.env` to enable Mara's language-model orchestration.

## Verification

```powershell
npm run catalogue:export
npm run catalogue:validate
npm run check
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm start
```

## Live catalogue

Set `GOOGLE_SHEET_ID` to a public workbook with the tabs generated by
`npm run catalogue:export`. The API validates the full candidate bundle before
publishing a new snapshot. Invalid refreshes cannot partially replace the last
known-good catalogue.

This prototype reports recorded dimensions, evidence, constraints, and encoded
clearances. It is not an installation or exercise safety assessment.
