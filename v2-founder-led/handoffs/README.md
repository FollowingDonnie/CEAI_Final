# Handoff Contract

The Manager owns the handoff chain and requires these files:

1. `01-research-implementation-brief.md`
2. `02-solution-design-specification.md`
3. `03-build-and-validation-handoff.md`
4. `04-communication-and-go-to-market.md`
5. `05-manager-executive-summary.md`

Every handoff must include:

- inputs actually read;
- decisions made and their authority: founder charter, evidence, or implementation
  constraint;
- assumptions and unresolved unknowns;
- artefacts created or changed;
- validation performed and failures remaining;
- precise instructions for the next role.

Agents edit their own numbered handoff. The Manager may annotate gate results but
must return failed work to the owning agent rather than silently repairing the
substance itself.
